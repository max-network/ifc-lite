`addDistributionSystemToStore` takes an optional `Type` to write a subtype such as IfcDistributionCircuit, and `PartOf` to aggregate the new system into a parent system through IfcRelAggregates. `assignToProductInStore` writes an IfcRelAssignsToProduct, for example a circuit assigned to the port that feeds it.
